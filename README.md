# Verb — to, for и глаголы

Личное приложение для iPhone, iPad и компьютера. Практический курс для русскоговорящего взрослого: B1 → B2, 26 тем, 130 моделей, 260 заданий. Постоянная ссылка: https://evgk724.github.io/verb-to-for/

## Учебный подход

Глаголы изучаются вместе с продолжением: `listen to a podcast`, `wait for a reply`, `decide to go`. Отдельно разобраны предлог **to** и маркер инфинитива, `to + -ing`, `for + -ing`, человек перед инфинитивом, два дополнения в одной фразе и соседние модели без предлога. Это широкий практический набор уровня B1–B2, а не исчерпывающий перечень всех английских глаголов и значений.

В каждой теме пять моделей и десять контекстных примеров. Объяснения на русском, типичная ошибка, короткая опора для памяти. Перевод и пояснение примера раскрываются по нажатию. Каталог ищет по глаголу, русскому смыслу и примерам; варианты с to и for у одного глагола можно сравнивать.

Практика: выбор, ввод без вариантов, исправление фразы, объяснение причины, аудирование с Ryan, устное восстановление с самостоятельной оценкой. Приложение не распознаёт речь. При проверке исправления сохраняйте исходные слова: проверяется модель, а не любой возможный перевод. `Help me understand` и `help me to understand` оба принимаются.

## Повторения

Базовые интервалы: 1, 3, 7, 14, 30, 60, 120 и 180 дней. «Легко» пропускает ступень, «С трудом» сокращает интервал. Ошибка возвращается после нескольких других заданий (к концу занятия — раньше), не более одного раза за занятие. После ошибки карточка назначается через 10 минут; успешное исправление в том же занятии возвращает её на следующий день. Дополнительная ранняя практика не увеличивает срок искусственно.

Личная ошибка уходит из списка после успешных ответов в два разных последующих дня. Режим «На сегодня» начинает с повторений, затем добавляет новые задания по порядку. Это понятная адаптация по ответам; индивидуально оптимальные интервалы не обещаются.

## Установка на iPhone / iPad

1. Откройте постоянную ссылку в Safari.
2. Нажмите «Поделиться» → «На экран “Домой”».
3. Если есть переключатель «Открывать как веб-приложение», включите его, затем нажмите «Добавить».
4. Начинайте занятия из новой иконки **Verb**.

Тёмная графитовая тема и спокойные тёмные кнопки. Основной текст по умолчанию 18 px, в настройках 20 или 22 px; английские примеры и задания крупнее. Размеры адаптируются к экрану.

## Голос, офлайн, данные

452 заранее подготовленные записи **Microsoft en-GB-RyanNeural**, британское произношение. Исходный темп немного замедлен; в настройках 0,8× / 1× / 1,15×. Голос браузера не подставляется вместо Ryan. При первом проигрывании нужен интернет, если запись ещё не сохранена.

В настройках нажмите **«Сохранить уроки и аудио»** и дождитесь завершения с открытым приложением. После этого уроки, тренировка и полный комплект аудио доступны офлайн. iOS может освободить хранилище при нехватке места.

Прогресс, ошибки и настройки хранятся только на устройстве. Автоматической синхронизации iPhone/iPad нет. В настройках можно экспортировать JSON и восстановить его на другом устройстве после подтверждения. Очистка данных сайта удаляет локальный прогресс; Safari и установленное приложение могут использовать отдельные хранилища. Копии Tense и Article в Verb не импортируются.

## Разработка и проверка

Статическое приложение без сборки, рекламы, аналитики, аккаунта и внешних библиотек в рабочем интерфейсе. Файлы HTML/CSS/ES modules, JSON и MP3. Запуск через HTTP(S), не двойным нажатием на `index.html`.

`node --test tests/engine.test.mjs tests/sw.test.cjs` проверяет учебный набор, допустимые ответы, повторы, резервные копии, аудио, офлайн и HTTP Range для Safari.

`node tests/browser.cjs` проверяет Chromium; `QA_BROWSER=webkit node tests/browser.cjs` — WebKit. Для локального отдельного WebKit можно задать `WEBKIT_PATH`. Нужен Playwright 1.62.1 и соответствующий браузер. Проверяются экраны телефона/планшета, шрифты 18/22, каталог, разные режимы, ошибка с отложенным повтором, пауза, экспорт/импорт, фактическое проигрывание MP3 и офлайн. CI запускает оба браузера.

Ключ прогресса `verb-progress-v1`, кэши `verb-shell-*` / `verb-audio-v1`, область service worker `/verb-to-for/`. Обновления этой PWA не удаляют кэши других учебных приложений на том же домене.
